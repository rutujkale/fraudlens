## Intended use

- **Intended for:** a portfolio / research artifact that demonstrates an end-to-end
  fraud-risk pipeline (simulator → features → models → calibration → cost policy →
  serving → monitoring), with honest evaluation and documented limitations.
- **Not intended for:** real credit/approval decisions, real customers, or any
  regulated use. The data is synthetic; the cost parameters are illustrative.

## Data

- **Primary:** simulated transactions (profile `{{freeze.profile}}`), split
  temporally into train / validation / test with an embargo of
  `{{freeze.split_boundaries.embargo_days}}` days (the maximum label delay).
  Train {{freeze.split_sizes.n_train}} rows, validation {{freeze.split_sizes.n_val}},
  test {{freeze.split_sizes.n_test}}.
- **Secondary:** IEEE-CIS Fraud Detection (Kaggle) for an external-transfer
  experiment only. The dataset is **not** redistributed; it was accessed twice

  (enforced by `features.registry.assert_no_target_columns`).

## Target and evaluation

- **Target:** probability that a transaction is fraudulent, within its temporal
  window.
- **Evaluation:** strictly temporal (chronological split + embargo). Primary metric
  is PR-AUC with a **cluster bootstrap over customers** (n=500, seed
  {{meta.seed}}); accuracy is reported only as a footnote.
- **Test window:** evaluated once, through `evaluation/guard.py`, on
  {{composition.rows}} rows / {{composition.frauds}} frauds
  (prevalence {{composition.prevalence:.5f}}).

## Calibration

- Frozen calibrator: sigmoid, selected on `val_thr` (the later half of validation).
- Brier (raw → calibrated): {{calibration.xgb.brier_raw:.6f}} →
  {{calibration.xgb.brier_calibrated:.6f}}. ECE (raw → calibrated):
  {{calibration.xgb.ece_raw:.6f}} → {{calibration.xgb.ece_calibrated:.6f}}.
- A raw model score is **not** a trustworthy risk number: the sigmoid calibrator
  is applied before any expected-cost decision, and the amount-dependent threshold
  is only valid on calibrated probabilities.

## Decision policy and cost assumptions

- Per transaction with calibrated probability `p` and amount `A`, the system
  compares expected costs of APPROVE / STEP_UP / REVIEW / BLOCK; risk levels
  derive from the chosen action, not from fixed probability cutoffs.
- Costs (INR): alpha {{freeze.cost_params.alpha}} of the amount lost,
  fixed fee {{freeze.cost_params.fixed_fee}}, review cost
  {{freeze.cost_params.review_cost}}, friction {{freeze.cost_params.friction_cost}},
  step-up {{freeze.cost_params.stepup_cost}}/{{freeze.cost_params.stepup_friction}}
  (stop rate {{freeze.cost_params.stop_rate}}), block friction
  {{freeze.cost_params.block_friction}}.
- Analyst capacity {{freeze.capacity_per_day}}/day (avg daily volume
  {{freeze.avg_daily_volume:.1f}}). On the test window
  {{headline.decision.capacity}}.
- Result: realized-cost reduction versus F1-optimal **{{headline.decision.reduction}}**

## Subgroup analysis (synthetic)

- The fairness audit (`docs/fairness_audit.md`) reports per-group operating metrics
  for the frozen policy, with cells of fewer than 30 positives or 1,000 rows
  suppressed. On synthetic data the group gaps reflect the **simulator's
  assumptions**, not demographic reality; the audit is not a compliance claim.

## Known limitations

- Synthetic simulator: assumptions about behavior, device sharing and fraud
  scenarios shape every result; the sim-to-real gap is measured only against
  IEEE-CIS and only on the shared feature subset.
- {{composition.frauds}} test frauds → wide intervals.
- Profile `main` was never generated; results are `dev`-only.
- Latency is an in-process lower bound ({{headline.engineering.latency}};
  rule: {{headline.engineering.latency_rule}}).
- `ruff format` is not enforced (see `docs/limitations.md`).

## Ethical considerations

- No real personal or financial data is used. External benchmark data is not
  redistributed and is used only for a research experiment.
- A production system would need fairness testing on real data, model-risk
  governance, appeal handling and monitoring of investigator feedback; none of
  that exists here.
